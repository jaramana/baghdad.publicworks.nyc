ڕاپۆرتکردنی کێشە

چوار هەنگاوەکە تەواو بکە بۆ وەرگرتنی ژمارەی ڕاپۆرت. بەو ژمارەیە بەدواداچوون بۆ ڕاپۆرتەکەت بکە.

ئەگەر مەترسی لەسەر ژیان هەبێت، وەک وایەری کارەبای ڕووت یان دەمی ئاوەڕۆی کراوە، سەرەتا پەیوەندی بە خزمەتگوزارییەکانی فریاکەوتنەوە بکە، پاشان لێرە ڕاپۆرتی بکە.

  1. کێشە
  2. شوێن
  3. وێنە و تێبینی
  4. پێداچوونەوە

کێشەکە چییە؟

لە کوێیە؟

لەسەر نەخشەکە کرتە لە شوێنی کێشەکە بکە، یان دەرزییەکە ڕابکێشە بۆ ئەوێ. ئەگەر ناتوانیت نەخشەکە بەکاربهێنیت، ناونیشان یان نیشانەیەکی نزیک لە خوارەوە بنووسە.

وێنە و تێبینییەک زیاد بکە

وێنە یارمەتی تیمەکە دەدات پێش گەیشتن خۆی ئامادە بکات.

ڕاپۆرتەکە وەرگیرا

ژمارەی ڕاپۆرت

لە ماوەی دوو ڕۆژی کاردا یەکەم وەڵام وەردەگریت. (نموونەیی)

بەدواداچوون بۆ ئەم ڕاپۆرتە بکە شتێکی تر ڕاپۆرت بکە

ژمارەی ڕاپۆرتەکە هەڵبگرە. لە هەر کاتێکدا دەتوانیت لە «بەدواداچوونی ڕاپۆرت» بەدواداچوونی بۆ بکەیت، بێ هەژمار.

دوای ڕاپۆرتکردن

  1. یەکسەر ژمارەی ڕاپۆرت وەردەگریت.
  2. ڕاپۆرتەکەت دەنێردرێت بۆ بەشی بەرپرس لە شارەوانییەکەت.
  3. تا داخستنی نوێکاری وەردەگریت.

بە تەلەفۆن یان ئەپ

پەیوەندی بە ٥٦٢٨ بکە، لە ٨:٣٠ی بەیانی تا ٢ی دوانیوەڕۆ، یان ئەپی ئەمانەت بەکاربهێنە، «دەنگی هاووڵاتیی بەغدا».

ڕاپۆرتەکانی تەلەفۆن و ئەپ دەچنە هەمان سیستەمی سکاڵاوە و دەتوانرێت لێرەش بە ژمارەکەیان بەدواداچوونیان بۆ بکرێت.
