ئەمڕۆ چیت پێویستە؟

گەڕان زیرەکی دەستکرد بەکاردەهێنێت و تەنها لە پەڕەکانی ئەمانەتەوە وەڵام دەداتەوە. چۆن کار دەکات

لە ماڵپەڕەکەوە

وێنەیەک زیاد بکە، شوێنەکە لەسەر نەخشە دیاری بکە و کێشەکە هەڵبژێرە. دوو خولەک دەخایەنێت.

دەست بە ڕاپۆرت بکە

لە واتسئەپەوە

وێنە و شوێنەکەت بنێرە بۆ ژمارەی ئەمانەت. ژمارەی ڕاپۆرت و هەموو نوێکارییەکان لە هەمان چاتدا وەردەگریت.

چاتەکە بکەرەوە

ژمارەیەکی پشتڕاستکراوە بە ناوی «ئەمانەتی بەغدا». هەرگیز لە واتسئەپدا داوای پارەت لێ ناکەین.

نموونە

ڕاپۆرتەکەت گەیشت. ژمارەکەی ب-٤٨٢١٣ە و نێردرا بۆ شارەوانی کەڕادە.
