بەدواداچوونی ڕاپۆرت

ژمارەی ڕاپۆرتەکەت بنووسە بۆ بینینی قۆناغەکانی و ئەو تیمەی کاری لەسەر دەکات. هەژمار پێویست نییە.

ب-٤٨٢١٣

ڕژانی ئاوەڕۆ · شارەوانی کەڕادە · نزیک قوتابخانەیەک لە مەحەللەی ٩٠٤

لە کاردایە
  1. ڕاپۆرتەکە وەرگیراپێنجشەممە ٢٩ی تشرینی یەکەم، ٨:١٢ی ئێوارە

    لە ماڵپەڕەکەوە، لەگەڵ وێنەیەک.

  2. نێردرا بۆ شارەوانی کەڕادەهەینی ٣٠ی تشرینی یەکەم، ٧:٤٠ی بەیانی

    بەشی ئاوەڕۆی شارەوانییەکە.

  3. تیمەکە لە شوێنەکەیەهەینی ٣٠ی تشرینی یەکەم، ١٠:٢٥ی بەیانی

    تیمێکی پاککردنەوەی ئاوەڕۆ کار لەسەر هێڵە لاوەکییەکە دەکات.

  4. داخستنی ڕاپۆرتچاوەڕێی تەواوبوونی کارەکە

  2. نێردرا بۆ شارەوانی دواتر

  4. داخستنی ڕاپۆرت

نموونەیەکی ڕوونکەرەوە.

ژمارەی ڕاپۆرتەکەم لە کوێ بدۆزمەوە؟

لە پەڕەی پشتڕاستکردنەوە دوای ناردن، و لە یەکەم نامەی دەقیدا.

چاککردنەوە چەند دەخایەنێت؟

لە ماوەی دوو ڕۆژی کاردا یەکەم وەڵام وەردەگریت. ماوەی چاککردنەوە بەندە بە کێشەکە. (نموونەیی)

ئەگەر ڕاپۆرتێک داخرا بەڵام کێشەکە مابوو؟

لە ڕاپۆرتەکەتدا «دووبارە کێشەکە ڕاپۆرت بکەرەوە» بەکاربهێنە. ڕاپۆرتە نوێیەکە ژمارە کۆنەکەی لەگەڵدایە، بۆیە هەردووکیان بەیەکەوە دەبەسترێنەوە.
